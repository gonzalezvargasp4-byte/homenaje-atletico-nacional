# 🟢 Homenaje a Atlético Nacional - El Rey de Copas

¡Bienvenidos! Este proyecto es un sitio web de maquetación interactiva y adaptativa dedicado a rendir homenaje a la historia, los ídolos y las grandes glorias del **Club Atlético Nacional**, el equipo más laureado de Colombia.

## 🚀 Características del Proyecto
- **Diseño Adaptativo (Responsive Web Design):** El sitio se adapta fluidamente a pantallas de computadores, tablets y teléfonos celulares utilizando metodologías modernas de CSS.
- **HTML5 Semántico:** Estructuración limpia utilizando etiquetas nativas (`<header>`, `<main>`, `<section>`, `<article>`) para una mejor accesibilidad y SEO.
- **Secciones Clave:** 
  - Pantalla de bienvenida con el render futurista del Nuevo Atanasio Girardot.
  - Altar de Leyendas con tarjetas dinámicas (efecto *hover*) de René Higuita, Andrés Escobar y Franco Armani.
  - Vitrina de la Gloria destacando las Copas Libertadores de 1989 y 2016.

## 🛠️ Tecnologías Utilizadas
- **HTML5**
- **CSS3** (Flexbox, Media Queries y Animaciones)
- **Google Fonts** (Tipografía Montserrat)

## 🎓 Fundamentación Técnica
El desarrollo de este sitio web consolidó los conceptos prácticos aprendidos en la certificación de **[Diseño Web Adaptativo de freeCodeCamp](https://freecodecamp.org)**.
